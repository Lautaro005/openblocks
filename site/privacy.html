En corto: OpenBlocks no tiene cuentas, servidores ni analítica. Tus notas quedan en tu carpeta. La app solo se conecta a internet cuando vos usás algo que lo necesita.

Qué guarda y dónde

DatoDónde
Páginas, carpetas y archivosEn tu vault, la carpeta que elegiste
Historial de versiones, papelera, conversaciones con la IA, vistas de bases de datos<vault>/.openblocks/
Ajustes, vaults recientes y claves de API~/.openblocks/settings.json, legible solo por tu usuario

Nada de eso se envía al autor ni a terceros. Borrar esas carpetas borra los datos.

Cuándo se conecta a internet

  • IA con un proveedor en la nube. Si elegís Claude Code, Codex, Anthropic, OpenAI, OpenRouter u otra API, lo que mandás en el chat (y la página que va como contexto) viaja a ese proveedor, bajo tu cuenta y sus términos. Con Ollama o LM Studio todo queda en tu equipo.
  • Búsqueda web. Solo con la pill Web encendida: las consultas van a DuckDuckGo y las páginas que el agente lee se descargan directamente.
  • Modelos locales. Si tocás Descargar en Ajustes → IA → Modelos locales, se bajan llama.cpp de GitHub y Gemma 4 o EmbeddingGemma 2 de Hugging Face. Después corren en tu equipo: las imágenes y PDFs que leen no salen de tu compu. Si tenés Lumina, se usan sus modelos.
  • Importar desde Notion. Solo si lo usás (Ajustes → Importar). Con un token, OpenBlocks le pide tus páginas a la API de Notion y baja los archivos que Notion guarda; el token se usa para esa importación y no se guarda. Con la exportación .zip no se conecta a nada: todo pasa en tu equipo.
  • Acceso remoto por URL. Apagado de fábrica. Si lo prendés, el servidor MCP se publica con un túnel de Cloudflare: los agentes que tengan la URL (con su token secreto) pueden leer y, si no está en solo lectura, cambiar tus vaults, y ese tráfico pasa por Cloudflare.
  • Actualizaciones. La app consulta la API pública de GitHub para saber si hay una versión nueva (se apaga en Ajustes → General).
  • Familia WorkStudio. brain, Lumina y OpenCue corren en tu equipo; OpenBlocks les habla por 127.0.0.1.

El servidor local

OpenBlocks escucha solo en 127.0.0.1 (y el acceso remoto, si lo prendés, publica únicamente el servidor MCP con su token). Rechaza pedidos con un nombre de host ajeno y exige un encabezado propio en todo lo que modifica datos, así una página web no puede usarlo desde tu navegador.

Este sitio

El sitio es estático, sin cookies ni analítica. Está en GitHub Pages, que puede registrar datos técnicos de acceso según la política de GitHub. El sitio consulta la API pública de GitHub para mostrar la última versión.

Contacto

In short: OpenBlocks has no accounts, no servers and no analytics. Your notes stay in your folder. The app only goes online when you use something that needs it.

What it stores and where

DataWhere
Pages, folders and filesIn your vault, the folder you chose
Version history, trash, AI conversations, database views<vault>/.openblocks/
Settings, recent vaults and API keys~/.openblocks/settings.json, readable only by your user

None of it is sent to the author or to third parties. Deleting those folders deletes the data.

When it goes online

  • AI with a cloud provider. With Claude Code, Codex, Anthropic, OpenAI, OpenRouter or another API, what you send in the chat (and the page sent as context) goes to that provider, under your account and its terms. With Ollama or LM Studio everything stays on your computer.
  • Web search. Only with the Web pill on: queries go to DuckDuckGo and pages the agent reads are downloaded directly.
  • Local models. If you press Download in Settings → AI → Local models, llama.cpp comes from GitHub and Gemma 4 or EmbeddingGemma 2 from Hugging Face. Then they run on your computer: the images and PDFs they read never leave it. If you have Lumina, its models are used.
  • Import from Notion. Only if you use it (Settings → Import). With a token, OpenBlocks asks Notion's API for your pages and downloads the files Notion hosts; the token is used for that import and not saved. With the .zip export nothing goes online: it all happens on your computer.
  • Remote access by URL. Off by default. When you turn it on, the MCP server is published through a Cloudflare tunnel: agents with the URL (and its secret token) can read and, unless it is read-only, change your vaults, and that traffic goes through Cloudflare.
  • Updates. The app asks GitHub's public API whether there is a new version (turn it off in Settings → General).
  • WorkStudio family. brain, Lumina and OpenCue run on your computer; OpenBlocks talks to them on 127.0.0.1.

The local server

OpenBlocks listens only on 127.0.0.1 (remote access, if you turn it on, publishes only the MCP server, behind its token). It rejects requests with a foreign host name and requires its own header on everything that changes data, so a web page cannot use it from your browser.

This website

The site is static, with no cookies and no analytics. It is hosted on GitHub Pages, which may log technical access data under GitHub's policy. It calls GitHub's public API to show the latest version.

Contact

Questions or requests: open an issue on GitHub. For security matters, follow SECURITY.md.
